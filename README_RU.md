# TBH_MoltyScriptPack

Коллекция пользовательских JavaScript-скриптов автоматизации и утилит, разработанных для ускорения процессов риггинга, компоновки анимации и очистки проектов в **Toon Boom Harmony**.

---

## 🚀 Включенные скрипты и руководство по использованию

### 1. `Molty_Backdrop.js` — Автоматические подложки (Backdrops)
* **Что делает:** Автоматически создает и настраивает размер кастомной подложки вокруг выбранных нод, динамически присваивая ей имя на основе исходного пега или группы.
* **Как использовать (что выбрать):** 
  1. Выберите одну или несколько нод (Pegs, Groups или Reads) в окне Node View.
  2. Запустите скрипт. Вокруг них сгенерируется серая подложка с правильным именем.

### 2. `Molty_BG_Group_cleanV2.js` — Очистка фонов и настройка Master-структуры
* **Что делает:** Упрощает настройку фона путем создания пега `BG_Master-P`, организации слоев, дублирования рисунков с суффиксом `-bg` и удаления неиспользуемых селов (cels).
* **Как использовать (что выбрать):**
  1. Выберите ноды фоновых рисунков (`READ`) или группы (`GROUP`) в Node View.
  2. Запустите скрипт для автоматического построения иерархии и очистки неиспользуемых кадров.

### 3. `Molty_Curve_to_zero.js` — Сброс кривых модулей (Curve Modules)
* **Что делает:** Рекурсивно обходит выбранные ноды или группы, находит ноды `CurveModule` и сбрасывает их исходную ориентацию и длину в `0`.
* **Как использовать (что выбрать):**
  1. Выберите корневые группы или конкретные ноды кривых.
  2. Запустите скрипт, чтобы мгновенно обнулить целевые параметры.

### 4. `Molty_rename_CompPeg.js` — Умное переименование нод
* **Что делает:** Интеллектуально переименовывает выбранные пеги, композиты и группы на основе подключенных слоев рисунков или соглашений об именовании иерархии.
* **Как использовать (что выбрать):**
  1. Выберите ноды рисунков, композиты, пеги или группы, которые нужно переименовать.
  2. Запустите скрипт — он определяет наличие рисунков и применяет стандартное именование для остальных нод (`C-`, `-P`, `Def-`).

### 5. `Molty_xPivot_to_zero.js` — Центрирование X-поворотной точки (X-Pivot)
* **Что делает:** Выравнивает опорную точку (пивот) по оси X в значение `0`, сохраняя при этом текущий пивот по оси Y для выбранных пегов и нод чтения (Read).
* **Как использовать (что выбрать):**
  1. Выберите одну или несколько нод `PEG` или `READ`.
  2. Запустите скрипт для центрирования их пивотов по оси X.

### 6. `Molty composite AP rename.js` — Переименование композитов AutoPatch
* **Что делает:** Автоматически переименовывает ноды Composites с префиксом `AP-`, окрашивает их в красный цвет и привязывает к именам исходных рисунков.
* **Как использовать (что выбрать):**
  1. Выберите целевые ноды `COMPOSITE`, связанные с сетками AutoPatch.
  2. Запустите скрипт для автоматического переименования и цветовой кодировки.

### 7. `Molty Layers script.js` — Генератор структуры слоев
* **Что делает:** Полноценный UI-инструмент для быстрого добавления и организации стандартных слоев структуры Harmony (`OL`, `LA`, `CA`, `UL`, `AP`, группы AutoPatch и настройки текстурных каттеров / Texture cutter).
* **Как использовать (что выбрать):**
  1. Выберите ноду рисунка (`READ`).
  2. Запустите скрипт, чтобы открыть панель интерфейса, нажмите нужные кнопки комбинаций слоев (например, `OL-LA-CA-UL` или `LA-AP-CA`) и сгенерируйте структуру.

### 8. `Molty Line Thickness script.js` — Управление толщиной линий (независимо от масштаба)
* **Что делает:** Продвинутый элемент управления UI для настройки масштабирования толщины линий, не зависящего от масштаба, с поддержкой различных пресетов разрешений (FHD/4K) и базовых размеров.
* **Как использовать (что выбрать):**
  1. Выберите ноды рисунков персонажа (`READ`).
  2. Откройте диалоговое окно скрипта, настройте базовую толщину линий и коэффициенты разрешения, а затем примените изменения.

### 9. `Molty_all_subs.js` — Распределение таймингов сиквенсов на таймлайне
* **Что делает:** Автоматически собирает все тайминги рисунков из выбранной ноды Read, сортирует их в естественном порядке и расставляет последовательно на таймлайне, начиная с выбранного кадра.
* **Как использовать (что выбрать):**
  1. Выберите ноду `READ` (рисунок), которая содержит несколько рисунков.
  2. Запустите скрипт, введите номер начального кадра в появившемся диалоговом окне и нажмите **Apply**.
